# CareerGraph

CareerGraph is a graph-powered career exploration platform that helps developers discover relevant job opportunities by looking beyond simple keyword matching.

Instead of treating a candidate's skills, projects, and job requirements as isolated records, CareerGraph models the relationships between them using CognoDB. This allows the application to explore connections between a candidate's experience, demonstrated skills, related technologies, and job requirements to surface potential matches and identify skill gaps.

## Built With

- Next.js
- React
- JavaScript
- Tailwind CSS
- CognoDB
- Neo4j JavaScript Driver
- Supabase Authentication
- Zod
- Framer Motion
